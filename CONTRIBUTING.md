# Contributing to Basalt

Thanks for helping make private local AI easier to use on Apple devices.

1. Open an issue before a large architectural change.
2. Run `./Scripts/bootstrap.sh` once, then `./Scripts/test.sh` before a pull request.
3. Keep inference and model data on-device. New telemetry or hosted services are
   out of scope unless the community explicitly agrees to them.
4. Preserve VoiceOver labels, Dynamic Type, reduced-motion behavior, keyboard
   navigation, and both compact and regular-width layouts.
5. Do not commit models, generated Xcode projects, XCFrameworks, captures, or
   build products.

By contributing, you agree that your work is licensed under the MIT License.
